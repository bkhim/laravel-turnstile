# Code of Conduct

## Our pledge

We want this project to be a friendly, useful place for everyone. We welcome people of
all backgrounds and experience levels, whether you are reporting your first bug or you
have been writing Laravel code for years.

## Expected behaviour

- Be kind and patient, especially with people who are learning.
- Assume good intentions and ask questions before assuming the worst.
- Give helpful feedback about the code, not about the person.
- Respect different opinions and experiences.
- Keep discussions focused on making the package better.

## Unacceptable behaviour

- Harassment, insults, or personal attacks.
- Discriminatory language or jokes.
- Publishing someone else's private information.
- Sustained disruption of discussions or pull requests.
- Any behaviour that would make someone feel unwelcome.

## Scope

This code of conduct applies to issues, pull requests, discussions, and any other space
connected to this project.

## Reporting

If someone makes you feel unwelcome or unsafe, please contact the maintainer privately
through [GitHub](https://github.com/bkhim). Reports will be handled with care and
discretion.

## Enforcement

The maintainer may remove comments, close issues, or block accounts that do not follow
this code of conduct. We would much rather have a conversation first, so please reach out
if something is wrong.

## Attribution

This code of conduct is written for this project and is inspired by the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
